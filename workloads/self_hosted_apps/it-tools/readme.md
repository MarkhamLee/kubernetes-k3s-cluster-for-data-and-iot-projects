## Deploying IT-Tools

[IT Tools](https://github.com/CorentinTh/it-tools) is a collection of tools that can help sys admins, engineers, etc., for example:

* Generating UUIDs
* Encryption tools
* Creating cron tabs

and, many, many, many more. I couldn't find a Helm chart to my liking so I just wrote my own deployment manifest. It's a basic app, doesn't need storage, everything is local, simple to use and just one of those things that is very helpful to have around and I use it almost daily.
