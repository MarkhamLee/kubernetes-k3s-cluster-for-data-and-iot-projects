## Workload Archive - Old Installs

These are old installation methods for applications that are still running within the cluster, think:
* Moving from deploying an app with a Helm chart via an ArgoCD Umbrella chart and a values.yaml file, to individual K8s manifests or vice-versa. 
* Changing between Helm chart providers or significantly different values.yaml files. 

Keeping track of these items provides a historical record of how the cluster and its apps have evolved over time.
