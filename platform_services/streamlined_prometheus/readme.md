## Streamlined Prometheus

I currently use the [Rancher variant of the Kube Prometheus stack](https://github.com/rancher/charts/tree/dev-v2.12/charts/rancher-monitoring/107.0.0-rc.1%2Bup69.8.2-rancher.8) for cluster monitoring, due to the extra monitoring, UI, alerting, etc., capabilities it provides via the Rancher UI. However, I stil wanted to use Prometheus for pulling metrics data from devices (e.g., NAS, Firewalls) external to the cluster, and didn't want to mix those in with K3s specific monitoring, in order to keep queries, dashboards and the like separate. The solution was this highly streanmlined version of Prometheus that doesn't monitor any cluster resources, and just scrapes data from external sources. I.e., this will ignore your K3s/K8s cluster completely and only pull data from the targets you specify in the values.yaml file under "extra scrape configs".
